gmail-digest 隱私權政策

最後更新：2026-11-12

適用範圍

gmail-digest 是個人自用工具，只用於擁有者本人及經其同意授權的合作夥伴 Gmail 帳號。

存取的資料

  • 透過 Gmail API 以唯讀權限（gmail.readonly）讀取信件的標頭與內文，用來判斷哪些信件是合作邀約、是否已回覆。
  • 僅擁有者的主帳號另外取得寄信權限（gmail.send），而且只用來把摘要報告寄給該帳號自己。

資料的使用與處理

  • 信件資料在擁有者自己的電腦上處理；授權憑證只儲存在該電腦上。
  • 為了判斷信件是否為合作邀約並產生摘要，信件內容會傳送給 Anthropic 的 Claude AI 服務進行分類，處理方式依 Anthropic 的隱私權政策辦理。
  • 不會出售、出租或分享資料給其他任何第三方，也不會用於廣告。
  • 摘要報告保留 30 天後移除。

Google API 服務使用者資料政策

gmail-digest 使用從 Google API 取得的資料時，遵守 Google API Services User Data Policy，包括其中的「有限使用」（Limited Use）規定。

撤銷授權

任何已授權的帳號都可以隨時到 Google 帳戶 → 第三方存取權 移除 gmail-digest 的存取權限。

聯絡方式

如有疑問，請透過 GitHub 聯絡擁有者。
